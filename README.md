# 物理题库（线上静态产物）

个人物理题库：上传试卷 → 自动解析切割 → 智能标注 → 检索组卷 → 导出打印。

本仓库只存放**构建后的静态产物**（GitHub Pages 托管用），源码在本地开发仓库 `D:/物理题库` 中维护。

- **当前版本**：`2026.10.11-2303`
- **构建时间**：见 `index.html` 或应用内「设置」页顶部
- **本地版使用**：双击 `D:/物理题库/启动本地版.cmd`，浏览器打开 `http://127.0.0.1:3000/`

## 重要提示

GitHub Pages 只能展示前端界面，**登录和数据写入目前不可用**：应用后端（WorkBuddy 云服务）对 GitHub Pages 的来源域名做了 CORS 限制，`github.io` 的预检请求会收到 `403 Forbidden`。要让 GitHub Pages 也能登录，需要增加一个用户自有的跨域代理（如 Cloudflare Worker），或等 WorkBuddy 发布环境恢复后使用官方域名。

## 更新流程

1. 本地执行 `npm run release -- --note "改动说明"` 生成新版本产物
2. 把 `dist/` 内容同步到本仓库根目录，并补上 `404.html`（内容同 `index.html`，用于前端路由深链兜底）
3. 提交并推送到 `main` 分支，GitHub Pages 会自动重新部署
